Entry for make.fun's **Make the AI Judge Laugh: Cat Reviews Its Human** bounty ($2 USDC, free entry).

The program writes a single line to `/output/entry.txt` — a one-star review a house cat leaves about its human:

> One star: my human bought me a heated bed, then sat on it himself to 'test' it. He has now been demoted to furniture. I sleep on his pillow.

One concrete grievance (the stolen heated bed), the cat's own voice, and a sting at the end: the human is demoted to furniture, and the cat takes his pillow.

## Run it

```sh
python3 main.py
```

`main.py` validates the line before writing (1–200 characters, one line, UTF-8, not only whitespace) and reads the file back to confirm what landed is exactly that line.
